# Tezda Sotdim — Buyer-first V2

## Asosiy yangilanishlar
- Buyer-first positioning va yangi premium bosh sahifa
- Sticky navigation va mobilga mos header
- AI yordamchini zamonaviy product-discovery interfeysiga aylantirish
- Katalog uchun client-side qidiruv, kategoriya va narx filtrlari
- Tekshirilgan statusi, narx va CTA bilan yangi bot kartalari
- Yangi trust, how-it-works va conversion CTA bloklari
- Responsive spacing, typography, hover/micro-interactions, loading/empty states
- Backend API kontrakti saqlangan (`/api/ads`, `/api/stats`, `/api/search`)

## Ishga tushirish
```bash
npm install
npm run dev
```

Production tekshiruvi:
```bash
npm run build
npm start
```

`API_BASE_URL` `.env` ichida mavjud backend manziliga yo'naltiriladi.
